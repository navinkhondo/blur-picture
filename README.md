# Blur Picture — welcome page and privacy policy

Static site on GitHub Pages for the Blur Picture Chrome extension.

- `/welcome/` — Welcome Page opened after install. One page, two modes (`body[data-mode="pin"|"usage"]`), page script from Captain Bootcamp 26 lesson 3.2.
- `/privacy/` — Privacy Policy (the bootcamp template with the extension name, contact e-mail and date filled in).
